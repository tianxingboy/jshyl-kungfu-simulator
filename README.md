# 金书红颜录5.60 武功学习规划模拟器

适用于《金书红颜录》青青子衿 v5.60 版本的武功学习规划工具。从游戏存档直接读取秘籍数据和队友列表，支持武功学习/洗武功模拟、属性计算、升级加点、周目上限等功能。

## 功能特点

- **从存档动态读取**：秘籍数据、队友列表、周目难度全部从游戏存档读取，无需手动维护数据库
- **武功学习模拟**：支持学习武功（升10级）和洗武功（升9级），自动计算属性加成
- **升级加点系统**：每级攻防轻+2，根据资质获得自由属性点，支持手动输入加点
- **周目上限计算**：根据周目和天书数量计算等级上限、属性上限、武功格上限
- **明玉丹格子**：按资质规则计算额外武功格数量，原始主角固定7颗
- **角色洗武功模板**：内置100+可加入队友的洗武功模板，一键导入
- **特殊书籍支持**：医毒书籍、洗髓经等无练出武功的秘籍不占格子但加成生效
- **内力性质系统**：支持阴/阳/调和三种内属，部分秘籍学习后改变内属
- **导入导出**：支持模拟方案的导入导出，方便分享和备份

## 运行环境

- Windows 10/11
- Python 3.10+（源码运行）
- 或直接使用打包好的 exe（无需 Python）

## 快速开始

### 方式一：直接运行 exe（推荐）

1. 下载 `金书武功模拟器.exe`
2. 双击运行，程序自动加载内置初始存档
3. 点击「打开存档」选择你的游戏存档（`jshyl_save*.zx5`）

### 方式二：源码运行

```bash
# 安装依赖
pip install openpyxl

# 运行
python gui.py
```

## 使用说明

### 1. 读取存档

- 启动时自动加载内置初始存档
- 点击「打开存档」选择你的游戏存档文件（`.zx5` 格式）
- 支持初始存档（save0）和正常存档（save1+），自动识别人物数据偏移

### 2. 选择角色

- 左侧队友列表显示所有可加入队友（238人）
- 支持搜索过滤
- 点击角色名加载该角色的初始属性和已学武功

### 3. 武功学习

- 右侧武功库按分类显示：拳掌、御剑、兵器、指腿、暗毒、内功、轻功、特殊
- 双击秘籍学习（升10级），Ctrl+双击洗武功（升9级）
- 学习条件自动检查：资质、内属、门派、家族、指定人物、属性需求等
- 已学武功显示在「修炼武功」栏，双击可删除（初始武功不可删除）

### 4. 升级加点

- 在「升级规划」中输入目标等级，点击应用
- 剩余根骨点显示在加点列下方
- 在属性输入框中输入加点数值，回车保存
- 支持重置加点和重置当前人物状态

### 5. 角色模板

- 点击「人物模板」加载该角色的洗武功模板
- 模板按格子顺序排列，可选择性导入
- 原始主角可同时载入复制人模板和原始主角模板

### 6. 特殊书籍

- 洗髓经、医毒书籍等无练出武功的秘籍不占武功格子
- 学习后加成生效，显示在「已学特殊书籍」栏
- 双击可删除

## 项目结构

```
kungfu_sim/
├── gui.py              # GUI 主程序
├── simulator.py        # 模拟器核心逻辑
├── save_reader.py      # 存档解析（人物数据）
├── item_reader.py      # 秘籍数据解析
├── kungfu_db.py        # 武功数据结构和工具函数
├── kf_mapper.py        # 武功编号映射
├── book_config.json    # 秘籍分类和等级配置
├── teammates.json      # 可加入队友映射
├── kungfu_list.json    # 武功列表数据
├── jshyl_save0.zx5     # 内置初始存档
├── unpack.exe          # 存档解包工具
├── templates/          # 角色洗武功模板（100+）
└── .gitignore
```

## 数据来源

- 秘籍数据：从存档 `R.grp` 动态读取（道具表，934个道具）
- 队友数据：从存档 `R.grp` 动态读取（2480个人物，筛选238个可加入队友）
- 武功分类：参考 `武功秘籍.xlsx` 和 `武功列表.xlsx`
- 洗武功模板：参考 `金书5.52隐藏物品.docx`

## 注意事项

- 本工具仅用于游戏规划，不会修改游戏存档
- 模拟器中的属性计算基于游戏机制，可能存在细微差异
- 建议在游戏中实际操作前用模拟器规划好路线
- 支持 v5.60 版本，其他版本可能存在数据结构差异
